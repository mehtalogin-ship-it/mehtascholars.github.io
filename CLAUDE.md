# CLAUDE.md

**Read `AGENTS.md` in this repo before making any change.** It is the contributor guide for
this site and it applies to you.

The single rule that matters most, repeated here because getting it wrong is silent:

> **Never edit anything inside `public/`** (except `public/css/styles.css` and
> `public/js/main.js`, which are hand-written). Everything else in `public/` is generated by
> `gen_site.py` from `captured/*.json`, and hand-edits are erased the next time it runs.

Edit the source, then run `python3 gen_site.py`, then commit both.

**Pushing to `main` publishes to the live public website.** Ask before you push.
